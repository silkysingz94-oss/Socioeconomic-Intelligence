07 / METHODOLOGY

VIIRS imagery is displayed through NASA GIBS. Quantitative zonal statistics are calculated separately from a supplied GeoTIFF. Pixel centres are tested against each EA polygon. Mean, maximum, minimum, standard deviation, sum and valid pixel count are calculated from valid cells.

This browser implementation requires a north-up EPSG:4326 GeoTIFF. Reproject other coordinate systems before upload. Results depend on the source raster, band, scale, offset, no-data value and temporal composite.
