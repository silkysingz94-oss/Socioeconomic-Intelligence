12 / METHODOLOGY AND LIMITATIONS
Image processing
NASA VIIRS ENCC tiles are requested, clipped to the selected administrative geometry and recoloured using a continuous browser-side colour ramp.

Statistics
Pixel values are sampled from successfully loaded image tiles. The charts describe the loaded tile sample, not necessarily the complete selected area.

Important
The ENCC display index is not calibrated radiance. For scientific radiance analysis, use the original quantitative VIIRS raster, apply quality filtering and calculate zonal statistics in a suitable GIS or raster-processing workflow.
