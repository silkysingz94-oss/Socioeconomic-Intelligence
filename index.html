09 / METHODOLOGY
Boundary clipping
Satellite imagery is clipped using the selected GeoJSON polygon geometry. Pixels outside the selected district, ward or EA are made transparent.

Data interpretation
NASA GIBS VIIRS Day/Night Band ENCC is a rendered image product. Pixel values are visual brightness indices from 0–255, not physical radiance values in nW/cm²/sr. For scientific radiance analysis, use a quantitative VIIRS raster product and quality-controlled zonal statistics.
